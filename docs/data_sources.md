# Data Sources

## HALO 2026 Competition Data

This project uses tracking-enhanced event data from 480 games in the 2023-24 AHL season, curated for the HALO 2026 competition.

The dataset combines event data such as faceoffs, passes, puck recoveries, dump-ins, and shots with player location data at the moment of the event.

Because tracking data is derived from broadcast video, player location data may be incomplete for some events.

Raw data is stored locally under:

`data/raw/halo_2026/`

Raw data is not committed to GitHub.
