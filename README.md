# Outside Shot Value

## Working Title

When Are Outside Shots Worth Taking?

## Purpose

This project studies when 5v5 outside shots create enough secondary value through rebounds, deflections, follow-up chances, or possession continuation to justify the decision to shoot.

## Current Stage

Stage gate: 30% concept feasibility and data intake.

## Project Structure

- `data/raw/`: local raw data only, not committed to GitHub
- `data/processed/`: derived data, not committed yet
- `notebooks/`: exploration and presentation notebooks
- `src/`: reusable Python code
- `figures/`: exported charts
- `reports/`: final memo and portfolio writeups
- `docs/`: project decisions and definitions
